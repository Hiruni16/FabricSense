📋 How to Use the Fabric Library

Follow these steps to identify fabrics using our dataset images:

  1. Copy your Ten Fabric Dataset folder to this project directory
  2. Rename the folder to fabric_dataset
  3. Folder structure should be:
    FabricSense/fabric_dataset/Chiffon/
    FabricSense/fabric_dataset/Cotton/
    FabricSense/fabric_dataset/Denim/
    ... (and so on for all 10 fabric types)
  4. Reload this page to see the fabric images
  5. Click any image to identify it using the AI model

Once you've copied the dataset folder, this page will display a gallery of all fabric samples!
